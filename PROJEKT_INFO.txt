API-ENDPOINTS (vad koden faktiskt använder)
--------------------------------------------
1. Väder (SMHI snow1g/v1):
   https://opendata-download-metfcst.smhi.se/api/category/snow1g/version/1/...
   Förväntar: timeSeries[].data.{air_temperature, wind_speed, relative_humidity, symbol_code}
   OBS: pmp3g/v2 lades ned 31 mars 2026

2. Elpris SE4:
   https://www.elprisetjustnu.se/api/v1/prices/{year}/{mm}-{dd}_SE4.json
   Förväntar: array med SEK_per_kWh och time_start

3. Börskurser (Yahoo Finance via api.allorigins.win):
   https://api.allorigins.win/raw?url=https%3A%2F%2Fquery1.finance.yahoo.com%2Fv8%2Ffinance%2Fchart%2F{symbol}%3F...
   Symboler: ^OMX, ^GSPC, ^IXIC, ^DJI
   Förväntar: chart.result[0].indicators.quote[0].close[]
   OBS: Yahoo Finance begränsar server-side requests – kan ge "Ej tillgänglig" vid blockering

4. Google Kalender (iCal via api.allorigins.win):
   https://api.allorigins.win/raw?url={encoded-ical-url}
   Förväntar: iCal-text med BEGIN:VEVENT-block

5. Nyheter SVT (RSS via api.allorigins.win):
   https://api.allorigins.win/raw?url=https%3A%2F%2Fwww.svt.se%2Fnyheter%2Frss.xml
   Förväntar: RSS XML med <item>-element

6. Nyheter DN (RSS via api.allorigins.win):
   https://api.allorigins.win/raw?url=https%3A%2F%2Fwww.dn.se%2Frss%2F
   Förväntar: RSS XML med <item>-element

7. AI-nyheter TechCrunch AI (RSS via api.allorigins.win):
   https://api.allorigins.win/raw?url=https%3A%2F%2Ftechcrunch.com%2Fcategory%2Fartificial-intelligence%2Ffeed%2F
   OBS: ersatte openai.com/news/rss.xml som inte längre existerar

8. AI-nyheter The Verge AI (Atom-feed via api.allorigins.win):
   https://api.allorigins.win/raw?url=https%3A%2F%2Fwww.theverge.com%2Fai-artificial-intelligence%2Frss%2Findex.xml
   OBS: Atom 1.0-format (<entry>/<link href="">/<published>) – koden hanterar båda RSS och Atom
   OBS: URL-format ändrat 2026-08-15 – theverge.com bytte från /rss/ai-artificial-intelligence/ till /ai-artificial-intelligence/rss/

9. Macworld Sverige (RSS via api.allorigins.win):
   https://api.allorigins.win/raw?url=https%3A%2F%2Fwww.macworld.se%2Ffeed

10. Bonnies matsedel – Hyllinge skola (astorp.se, HTML-tabeller):
    Primär: https://astorp.se/barn-och-utbildning/grundskola/hyllinge-skola.html
      Matsedeln är inbäddad direkt som HTML-tabeller på sidan (flera veckor visas samtidigt,
      t.ex. "Matsedel vecka 34/35/36/37"), kolumner Dag/Lunch/Vegetariskt. Ingen extern
      matsedelstjänst inblandad – kommunen publicerar texten själva i Sitevision-CMS:et.
    OBS: astorp.se blockerar TCP-anslutningar från datacenter-IP:er (bekräftat både från denna
      sandbox och från GitHub Actions-runners – connection timeout efter TLS-handskakning
      aldrig startar). Fungerar dock utmärkt via CORS-proxy (bekräftat 200 OK, 97 KB via
      cors.eu.org kört från GitHub Actions 2026-08-25) – troligen ett bot-/WAF-skydd riktat
      mot rena datacenter-anrop, inte mot proxy-IP:er eller vanliga webbläsare.
    Fallback-kedja i fetchBonnieLunch(): 1) astorp.se via api.allorigins.win/raw,
      2) astorp.se via cors.eu.org (bekräftat fungerande – se ovan), 3) skolmaten.se API v4
      (reserv – bekräftat NERE/404 för Hyllinge skola aug 2026, skolmaten.se:s RSS är också
      nedlagd; Home Assistant-komponenten Kaptensanders/skolmat bytte RSS→API v4 i sin v3.0.0
      men även deras API-anrop mot hyllinge-skola gav "Menu not found" vid test).
    Datum beräknas från "Matsedel vecka N"-rubriken + veckodagsnamn via ISO 8601-veckologik
    (isoWeekMonday/resolveLunchDate i dashboard.js); tomma/opublicerade dagar (t.ex. första
    dagarna i en ny vecka) hoppas över automatiskt.

11. Koenigsegg-nyheter (Google News RSS via api.allorigins.win):
    https://api.allorigins.win/raw?url=https%3A%2F%2Fnews.google.com%2Frss%2Fsearch%3Fq%3Dkoenigsegg%26hl%3Dsv%26gl%3DSE%26ceid%3DSE%3Asv
    OBS: Koenigsegg har ingen egen RSS/nyhetsflöde – Google News RSS-sök används istället.
    Titel trimmas från Google News " - Källa"-suffix; källnamn hämtas ur <source>-taggen.

CORS-PROXYER
------------
  Allt RSS/börs/kalender: https://api.allorigins.win/raw?url={encoded_full_url}
  OBS: corsproxy.io kräver betalplan (returnerar 200 med error-JSON) – använd INTE
  OBS 2026-08-25: cors.eu.org fungerar igen (bekräftat 200 OK för svt.se-RSS och astorp.se
    via GitHub Actions) – tidigare notering om 403/allowlist stämde inte längre vid omtest.
    Format: https://cors.eu.org/{full_url} (utan URL-encoding). Används som fallback för
    Bonnies matsedel (se punkt 10 ovan); inte bytt till global default då den inte testats
    mot samtliga övriga källor (Yahoo Finance, iCal m.fl.).
    Även codetabs.com och corsproxy.io testades 2026-08-25: båda gav fel/nere (522 resp 403).
