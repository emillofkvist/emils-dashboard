GITHUB

Branches:
  main      → källkod (pusha hit vid ändringar)
  gh-pages  → publicerad sajt (mergea från main efter push)

VIKTIGT – HÅLL DENNA FIL UPPDATERAD
-------------------------------------
  När du gör ändringar i projektet, uppdatera alltid PROJEKT_INFO.txt:
    - Lägg till nya moduler/datakällor under "MODULER & DATAKÄLLOR"
    - Uppdatera "INSTÄLLNINGAR I config.js" om nya config-nycklar tillkommer
    - Lägg till en rad under "SENASTE ÄNDRINGAR" med datum och beskrivning
  Inkludera PROJEKT_INFO.txt i git-commiten så den alltid är synkad med koden.


GIT-WORKFLOW (varje gång du gör ändringar)
------------------------------------------
  1. git add config.js dashboard.js index.html PROJEKT_INFO.txt
  2. git commit -m "Beskrivning av ändringen"
  3. git push origin main
  4. git checkout gh-pages
  5. git merge main
  6. git push origin gh-pages
  7. git checkout main

Ändringen syns live på GitHub Pages inom ~1 minut efter steg 6.


FILER
-----
  index.html    – All HTML och CSS. Lägg till nya kort/stilar här.
  dashboard.js  – All JavaScript-logik. Lägg till nya fetch-funktioner här.
  config.js     – API-URL:er, RSS-flöden, inställningar. Ändra källor här.

---------------------
  Datum/tid/vecka     – JavaScript (inbyggt)

                        Graf renderas med Chart.js (CDN)
  Börs                – Yahoo Finance (query1/query2) via cors.lol (primär) + allorigins.win (fallback)
                        Symboler: ^OMX, ^GSPC, ^IXIC, ^DJI
  Kalender            – Google Kalender via iCal-länk, proxy: allorigins.win/raw
  Nyheter (SVT + DN)  – RSS via api.rss2json.com, max 5 totalt (3 per källa)
  AI-nyheter          – TechCrunch AI + The Verge via api.rss2json.com, max 5
  Porsche-nyheter     – Carscoops, Road & Track, Motor1 via api.rss2json.com, max 5
  Koenigsegg-nyheter  – Carscoops (taggflöde), Road & Track, Motor1 via api.rss2json.com, max 5
  Pollenprognos       – https://api.pollenrapporten.se/v1/forecasts (Naturhistoriska riksmuseet)
                        Region: Malmö (UUID-baserad), 7-gradig skala, visar bara nivå > 0
  Apple Release Notes – Apple DocC JSON API via allorigins.win/raw
                        Visar alltid senaste iOS/iPadOS-release
                        Datum från developer.apple.com/news/releases/ (fallback: localStorage firstSeen)
                        Rubrik auto-översätts till svenska. Läsarläge renderar DocC JSON inline.
  Macworld Sverige    – https://www.macworld.se/feed  (senaste 24h)
  Macworld.com        – https://www.macworld.com/feed/  (senaste 24h, auto-översätts)

  Aftonbladet         – https://rss.aftonbladet.se/rss2/small/pages/sections/senastenytt/
                        (8 senaste nyheter)
  Hemnet (48h-nya)    – https://www.hemnet.se/bostader?item_types[]=villa&item_types[]=gard...
                        Cloudflare Worker (hemnet-worker/) kringgår Cloudflares bot-skydd
                        Hämtar __APOLLO_STATE__ via Hemnets _next/data JSON-endpoint
                        CONFIG.hemnet.workerUrl: sätt till Worker-URL efter deploy
                        Fallback: länkknapp om ingen Worker konfigurerad


CORS-PROXYER
------------
  RSS/nyheter (alla):   https://api.rss2json.com/v1/api.json?rss_url={encoded_url}
  Börs:                 fetchViaProxyChain() — cors.lol → allorigins.win/raw → r.jina.ai
                        (query2.finance.yahoo.com, sedan query1 om query2 helt misslyckas)
  Kalender (prim):      https://api.allorigins.win/raw?url={encoded_url}
  Kalender (fall1):     https://api.allorigins.win/get?url={encoded_url}
  Kalender (fall2):     https://r.jina.ai/{url}
  OBS: CONFIG.calendarProxy i config.js används INTE av fetchCalendar() — proxylistan är
       hårdkodad i funktionen (calProxies).
  Bonnie lunch (prim):  https://api.cors.lol/?url={encoded_url}
  Bonnie lunch (fall):  https://api.allorigins.win/raw?url={encoded_url}
  Bonnie lunch (fall2): https://r.jina.ai/{url}  (markdown-läsare, ej HTML — bonnieParseMarkdown())
  Apple Release Notes:  https://api.allorigins.win/raw?url={encoded_url}  (CONFIG.corsProxy)
  Reader (primär):      https://api.cors.lol/?url={encoded_url}
  Reader (fallback1):   https://api.allorigins.win/raw?url={encoded_url}
  Reader (fallback2):   https://r.jina.ai/{url}  (markdown-läsare, ej HTML — parseJinaMarkdown())
  OBS: corsproxy.io kräver betalplan sedan apr 2026 – returnerar 200+error-JSON, använd INTE.
  OBS: cors.eu.org returnerar 403 (nere) sedan 2026-04-30 – använd INTE.
  OBS: r.jina.ai kan svara 200 OK med JSON-felkropp om måldomänen är tillfälligt rate-limitad
       (t.ex. "AbuseAlleviationError") – kontrollera alltid att svaret innehåller
       "Markdown Content:"-markören innan det tolkas som en artikel.


TEKNISKT
--------
  - Ren HTML/CSS/JS, inga ramverk eller byggsteg
  - Mobilanpassad, max bredd 600px
  - All data laddas parallellt med Promise.all vid sidstart
  - Artikelförhämtning (prefetch) i bakgrunden efter 1 sekund
  - Reader-läge med Readability.js (CDN) – extraherar artikeltext
  - Auto-översättning via translate.googleapis.com (gratis, ingen nyckel)
    – Engelska artiklar översätts automatiskt när reader öppnas
    – Engelska rubriker i listan översätts för: AI-nyheter, Porsche, Macworld.com
  - Dark mode – sparas i localStorage
  - Debug-panel (🐛-knapp) – visar console.error/warn med tidsstämpel
